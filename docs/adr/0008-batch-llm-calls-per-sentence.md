# ADR-0008: LLM 呼び出しの粒度はセンテンス単位バッチ

## Context

遅延 5〜15 秒目標。毎単語だと費用爆発、セッション全文だと遅延過大。

## Options

1. 単語/トークン毎（ストリーミング翻訳）
2. 1〜3 センテンス毎
3. 30 秒窓毎
4. セッション終了時のみ

## Decision

**2. 1〜3 センテンス毎**

## Consequences

- Pros: 文脈が取れて翻訳精度が上がる。5〜15 秒遅延と整合
- Cons: センテンス境界判定（句点・長ポーズ）が必要。実装は Whisper の VAD + タイムスタンプで代用可
