# Requirements — 技術カンファレンス同時翻訳・解説アプリ

作成日: 2026-04-19

## 概要

技術カンファレンスの講演音声をリアルタイムに近い速度で日本語へ翻訳し、同時に用語・背景・Q&A 形式の解説を提供するパーソナルツール。

## 対象・スコープ

| 項目 | 内容 |
| --- | --- |
| プラットフォーム | マルチ対応が理想（技術制約で判断）。主な利用環境は macOS |
| 利用シーン | 自分一人用のパーソナルツール。認証・マルチテナント不要 |
| 月額コスト目標 | ~$10/月（API 費用） |

## 入出力

### 入力

- **音声**
  - マイク（会場の生音声）
  - 録音/録画ファイル（mp4, mp3 など）
  - 画面キャプチャやライブストリーム URL は対象外
- **事前コンテキスト**
  - 講演アブストラクト・タイトル（毎回投入）
  - スライド PDF（存在する場合は投入）
  - 登壇者プロフィールなど追加情報は任意
- **Q&A 入力**
  - テキストのみ（音声入力は使わない）
  - 自由記述とサジェストプロンプト（選択型）の両対応

### 出力

- **用語解説パネル** を中心に提示
  - 用語集型（短い定義）
  - 背景解説型（RFC・関連技術・歴史などの文脈追加）
  - Q&A 型（ユーザの質問に回答）
  - これら 3 種は UI で切替可能
- **言語ペア**: 英語 → 日本語
- **画面キャプチャ・OCR は行わない**（音声のみで完結）

## リアルタイム性

- 遅延 5〜15 秒を許容
- 精度優先。文脈を見てから翻訳・解説を生成
- 完全な同時通訳（1〜3 秒）は要件外

## 保存・エクスポート

- セッション終了時に **Markdown エクスポート**
- Notion 等に貼り付けて振り返り資料化できる粒度で保存
- 翻訳文、解説、用語集を含む

## 非機能

- パーソナルツールのためセキュリティ要件は最低限
- NDA 素材の扱いを考慮し、音声データを不必要に外部送信しない設計が望ましい
- オフラインでも STT まではできることが理想（ハイブリッド構成で担保）

## 想定外・将来検討

- スライド/画面 OCR 連携
- 自分の音声による Q&A 入力（話者分離の複雑さ回避のため見送り）
- 双方向言語ペア、日→英
- マルチユーザ・共有機能
